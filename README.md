# Two-Sentence Horror

Entry for the make.fun bounty [u-suroto-two-sentence-horror-acea9253](https://make.fun/bounty/u-suroto-two-sentence-horror-acea9253): the scariest horror story in exactly two sentences.

`main.ts` writes the story to `/output/entry.txt` and self-checks the gate (exactly two sentences, 1–400 characters) before exiting.

> For a week, the voice assistant in my kitchen has thanked me every night for the tea I never made. This morning it asked, in my own voice, whether I was finally ready to drink it.

## Run

```sh
node main.ts
```
